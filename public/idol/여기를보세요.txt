아이돌 음성 (mp3만 사용)

실시간 Voice ID / ElevenLabs API 재생은 꺼져 있습니다.
앱은 public/idol/{이름}.mp3 파일만 재생합니다.

필요한 파일:
  greeting.mp3  — 입장 환영
  hint1.mp3     — 1단계 힌트
  hint2.mp3     — 2단계 힌트
  hint3.mp3     — 3단계 힌트
  clear1.mp3    — 1단계 정답
  clear2.mp3    — 2단계 정답
  final.mp3     — 3단계 완료
  wrong.mp3     — 오답
  done.mp3      — 보상 받은 뒤

ElevenLabs에서 만든 mp3를 위 이름으로 이 폴더에 넣으면 됩니다.
(선택) npm run idol:voice 로 대사를 일괄 생성할 수도 있습니다.
