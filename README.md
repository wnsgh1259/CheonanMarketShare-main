
  # 천안시장 (공유)

  This is a code bundle for 천안시장 (공유). The original project is available at https://www.figma.com/design/QXuD4BTqROZY6Bwc1ppKr7/%EC%B2%9C%EC%95%88%EC%8B%9C%EC%9E%A5--%EA%B3%B5%EC%9C%A0-.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Naver Map setup

  1. Create `.env` in the project root.
  2. Copy the value from `.env.example`.
  3. Set your Naver Map client id:

  `VITE_NAVER_MAP_CLIENT_ID=your_naver_map_client_id`

  4. Register your development domain in Naver Cloud console
     (for local development: `http://localhost:5173`).
